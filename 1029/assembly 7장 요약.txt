

1. 시프트 및 로테이트 명령어 (Shift and Rotate Instructions)
-------------------------------------------------------------------
- 시프트/로테이트 명령어는 비트 단위 이동, 2의 거듭제곱 곱셈/나눗셈, 비트 필드 추출에 사용됩니다.
- SHL / SAL (Shift Left): 비트를 왼쪽으로 이동하고 LSB를 0으로 채우며, MSB는 Carry Flag(CF)에 저장됩니다.
- SHR (Shift Right): 부호 없는 정수의 논리 오른쪽 시프트로, MSB를 0으로 채우고 LSB는 CF에 저장됩니다.
- SAR (Shift Arithmetic Right): 부호 있는 정수의 산술 오른쪽 시프트로, 최상위 부호 비트를 유지합니다.
- ROL / ROR (Rotate Left/Right): 비트를 순환 회전시키며, 밀려난 비트는 CF와 반대쪽 끝으로 복사됩니다.
- RCL / RCR (Rotate Carry Left/Right): Carry Flag를 포함하여 비트를 회전시킵니다.
- 1비트 시프트/회전 시 결과가 부호 있는 표현 범위를 벗어나면 Overflow Flag(OF)가 1로 설정됩니다.
- SHLD / SHRD (Double-Precision Shift): 소스 피연산자의 비트로 목적지 피연산자의 빈 비트 공간을 채우며 왼쪽 또는 오른쪽으로 시프트합니다.
- 응용: 비트 조작을 통한 파일 날짜/시간 필드 추출, 이진 정수를 ASCII 이진 문자열로 변환.

/* 예제 코드: SHL/SHR 곱셈 및 나눗셈 */
mov dl, 5
shl dl, 1        ; DL = 10 (5 * 2)

mov al, 64
shr al, 3        ; AL = 8 (64 / 8)

2. 확장 가감산 (Extended Addition and Subtraction)
-------------------------------------------------------------------
- 32비트를 초과하는 다중 정밀도 정수의 덧셈과 뺄셈 연산을 지원합니다.
- ADC (Add with Carry): 목적지, 소스 피연산자에 이전 연산의 Carry Flag 값을 더합니다.
- SBB (Subtract with Borrow): 목적지 피연산자에서 소스 피연산자와 Carry Flag 값을 뺍니다.

/* 예제 코드: ADC 및 SBB 활용 */
mov dl, 0
mov al, 0FFh
add al, 0FFh     ; AL = FEh, CF = 1
adc dl, 0        ; DL = 1 (DL + 0 + CF)

3. 곱셈 및 나눗셈 명령어 (Multiplication and Division Instructions)
-------------------------------------------------------------------
- MUL (Unsigned Multiply): 부호 없는 곱셈을 수행하며, 연산 결과는 피연산자 크기의 2배(AX, DX:AX, EDX:EAX)에 저장됩니다.
  * 상위 절반 결과가 0이 아니면 Carry/Overflow 플래그가 설정되어 상위 레지스터 확인 필요 여부를 알려줍니다.
- IMUL (Signed Multiply): 부호 있는 곱셈을 수행합니다.
  * 단일 피연산자 형식 외에도 결과를 지정된 크기로 잘라내는 2개/3개 피연산자 형식을 지원합니다.
  * 2개 이상의 피연산자 형식 사용 시 잘림(truncation)이 발생하면 OF와 CF가 설정됩니다.
- DIV / IDIV: 부호 없는/부호 있는 나눗셈을 수행하며, 나눗셈 전 나누어지는 수(Dividend)를 부호 확장(CBW, CWD, CDQ)해야 합니다.

/* 예제 코드: MUL 및 IMUL 활용 */
mov al, 5h
mov bl, 10h
mul bl           ; AX = 0050h, CF = 0

mov eax, var1
mov ebx, 5
mul ebx          ; EDX:EAX = var1 * 5

4. ASCII 및 BCD 십진 산술 연산 (ASCII & BCD Arithmetic)
-------------------------------------------------------------------
- 비압축 십진수(Unpacked Decimal)는 상위 4비트가 0이며, ASCII 형식은 상위 4비트가 0011b (30h)입니다.
- AAA (ASCII Adjust after Addition): ADD/ADC 연산 후 AL의 바이너리 결과를 ASCII/비압축 BCD 형식으로 보정합니다.
- AAS (ASCII Adjust after Subtraction): SUB/SBB 연산 후 결과를 보정합니다.
- AAM (ASCII Adjust after Multiplication): MUL 연산 후 AX의 결과를 비압축 BCD로 변환합니다.
- AAD (ASCII Adjust before Division): DIV 나눗셈 연산 직전에 AX의 비압축 BCD dividend를 이진수로 변환합니다.
- DAA / DAS (Decimal Adjust): 압축 BCD(Packed BCD) 덧셈(ADD/ADC) 및 뺄셈(SUB/SBB) 후 결과를 압축 BCD 형식으로 보정합니다.

/* 예제 코드: AAA 및 DAA 활용 */
mov ah, 0
mov al, '8'      ; AX = 0038h
add al, '2'      ; AX = 006Ah
aaa              ; AX = 0100h (보정 완료)
or  ax, 3030h    ; AX = 3130h = '10' (ASCII 변환)

mov al, 35h
add al, 48h      ; AL = 7Dh
daa              ; AL = 83h (압축 BCD 보정 완료)
