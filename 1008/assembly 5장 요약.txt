

1. 런타임 스택과 스택 연산 (Runtime Stack & Stack Operations)
-------------------------------------------------------------------
- 런타임 스택 개념: CPU가 직접 관리하는 LIFO(Last In First Out) 구조의 메모리 영역.
- ESP 레지스터: 스택의 최상단(Top) 오프셋 주소를 가리킴 (스택은 높은 주소에서 낮은 주소로 확장).
- PUSH 명령어: ESP를 4 감소(32비트 기준)시킨 후 피연산자 값을 스택에 저장.
- POP 명령어: ESP가 가리키는 값을 목적지로 복사한 후 ESP를 4 증가.
- PUSHFD / POPFD: 32비트 EFLAGS 레지스터 전체를 스택에 저장 및 복원.
- PUSHAD / POPAD: 8개 범용 레지스터(EAX, ECX, EDX, EBX, ESP, EBP, ESI, EDI)를 일괄 저장 및 역순 복원.
- 스택의 주요 용도: 프로시저 복귀 주소 저장, 레지스터 상태 보존, 매개변수 전달, 지역 변수 공간 확보.

/* 예제 코드: PUSH / POP 및 스택을 이용한 문자열 뒤집기 */
.data
aName BYTE "I like Assembly", 0
nameSize = ($ - aName) - 1

.code
mov ecx, nameSize
mov esi, 0
L1:
    movzx eax, aName[esi]
    push eax            ; 스택에 문자를 PUSH
    inc esi
    loop L1

mov ecx, nameSize
mov esi, 0
L2:
    pop eax             ; 스택에서 LIFO 순서로 POP
    mov aName[esi], al  ; 역순 저장
    inc esi
    loop L2

2. 프로시저 정의 및 호출 (Defining and Using Procedures)
-------------------------------------------------------------------
- PROC / ENDP 지시어: 프로시저의 시작과 끝을 정의.
- CALL 명령어: 다음 실행할 명령어 주소(복귀 주소 EIP)를 스택에 PUSH하고 대상 프로시저로 이동.
- RET 명령어: 스택에서 복귀 주소를 POP하여 EIP로 복원하고 호출 위치 다음으로 돌아감.
- 중첩 프로시저 호출(Nested Procedure Calls): 스택을 통해 호출 순서의 역순으로 정확히 복귀함.

/* 예제 코드: 레지스터로 인자를 전달하는 프로시저 */
;-------------------------------------------------------------------
; SumOf: 세 정수의 합을 계산하여 EAX로 반환
; Receives: EAX, EBX, ECX
; Returns: EAX = sum
;-------------------------------------------------------------------
SumOf PROC
    add eax, ebx       ; EAX = EAX + EBX
    add eax, ecx       ; EAX = EAX + ECX
    ret                ; EAX에 결과값을 담고 복귀
SumOf ENDP

; 프로시저 호출부
mov eax, 10000h
mov ebx, 20000h
mov ecx, 30000h
call SumOf             ; EAX = 60000h 반환

3. 레지스터 보존 및 USES 연산자 (Saving & Restoring Registers)
-------------------------------------------------------------------
- 레지스터 보존 원칙: 프로시저 내부에서 수정되는 레지스터는 PUSH/POP으로 호출 전 상태로 복원해야 함.
- 예외 사항: 반환값(Return Value)으로 사용되는 레지스터(주로 EAX)는 PUSH/POP 하면 반환값을 잃으므로 보존하지 않음.
- USES 연산자: PROC 선언부에 지정 시 어셈블러가 시작 부분에 PUSH, ret 직전에 POP 코드를 자동 생성.

/* 예제 코드: PUSH/POP 직접 작성 vs USES 지시어 사용 */
; 1) PUSH/POP 직접 작성 방식
ArraySum PROC
    push esi           ; 레지스터 상태 보존
    push ecx
    mov eax, 0
L1:
    add eax, [esi]
    add esi, TYPE DWORD
    loop L1
    pop ecx            ; 역순 복원
    pop esi
    ret                ; EAX는 합계 반환값
ArraySum ENDP

; 2) USES 지시어를 사용한 동일 기능 작성 방식
ArraySum PROC USES esi ecx
    mov eax, 0
L1:
    add eax, [esi]
    add esi, TYPE DWORD
    loop L1
    ret                ; 어셈블러가 pop ecx, pop esi 자동 삽입
ArraySum ENDP

4. 외부 링크 라이브러리 및 Irvine32 라이브러리 (Irvine32 Library)
-------------------------------------------------------------------
- 링크 라이브러리: 미리 어셈블된 프로시저들의 오브젝트(.OBJ) 집합체.
- Irvine32 라이브러리: 32비트 Windows API(kernel32.dll)를 단순화하여 콘솔 입출력을 제공.
- 주요 제공 프로시저:
  * Clrscr: 콘솔 화면 지우기
  * Crlf: 줄바꿈(CR/LF) 출력
  * DumpRegs / DumpMem: 레지스터 및 메모리 상태 덤프 출력
  * ReadInt / WriteInt: 32비트 부호 있는 정수 입력 및 출력 (EAX)
  * ReadString / WriteString: 문자열 입력 및 출력 (EDX)
  * Randomize / RandomRange / Random32: 난수 생성 관련 함수
  * Delay: 지정된 밀리초 동안 실행 일시 정지
  * GetMSeconds: 자정 이후 경과된 시간을 밀리초 단위로 반환 (실행 시간 측정)

/* 예제 코드: Irvine32 라이브러리 활용 종합 예시 */
include [의심스러운 링크 삭제됨]

.data
prompt BYTE "Enter a 32-bit signed integer: ", 0
msg1   BYTE "Elapsed milliseconds: ", 0
startTime DWORD ?

.code
main PROC
    call Clrscr                 ; 화면 지우기

    ; 1. 정수 입력 및 출력
    mov edx, OFFSET prompt
    call WriteString            ; 프롬프트 출력
    call ReadInt                ; 정수 입력받아 EAX에 저장
    call WriteInt               ; 입력받은 값 10진수 출력
    call Crlf

    ; 2. 실행 시간 측정 (GetMSeconds)
    call GetMSeconds
    mov startTime, eax          ; 시작 시간 저장

    mov eax, 500
    call Delay                  ; 500ms 대기

    call GetMSeconds
    sub eax, startTime          ; 경과 시간 계산
    mov edx, OFFSET msg1
    call WriteString
    call WriteDec               ; 경과 시간(ms) 출력
    call Crlf

    call DumpRegs               ; 레지스터 상태 확인
    exit
main ENDP
END main
