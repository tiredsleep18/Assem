
### **4.9 Review Questions and Exercises**

#### **4.9.1 Short Answer (단답형 문제)**

1. **`movsx edx, one` (a) 및 `movsx edx, two` (b) 실행 후 EDX 값**
   * **(a) `FFFF8002h`**: `one`은 WORD 타입 `8002h`(최상위 비트 1, 음수)입니다. `MOVSX` 명령어로 32비트 확장 시 부호 비트(1)가 상위 비트로 채워집니다.
   * **(b) `00004321h`**: `two`는 WORD 타입 `4321h`(최상위 비트 0, 양수)입니다. 부호 비트(0)가 채워집니다.

2. **`mov eax, 1002FFFFh` / `inc ax` 실행 후 EAX 값**
   * **답:** **`10020000h`**
   * **해설:** `INC AX`는 16비트 레지스터 AX만 1 증가시킵니다 (`FFFFh` \\(\rightarrow\\) `0000h`). EAX의 상위 16비트(`1002h`)는 영향을 받지 않습니다.

3. **`mov eax, 30020000h` / `dec ax` 실행 후 EAX 값**
   * **답:** **`3002FFFFh`**
   * **해설:** `DEC AX`는 AX 값만 1 감소시킵니다 (`0000h` \\(\rightarrow\\) `FFFFh`). 상위 16비트(`3002h`)는 유지됩니다.

4. **`mov eax, 1002FFFFh` / `neg ax` 실행 후 EAX 값**
   * **답:** **`10020001h`**
   * **해설:** `NEG AX`는 AX(`FFFFh` = -1)의 2의 보수를 취해 `0001h`로 만듭니다. EAX 상위 16비트는 변하지 않습니다.

5. **`mov al, 1` / `add al, 3` 실행 후 Parity Flag(PF) 값**
   * **답:** **PF = 0 (Clear)**
   * **해설:** 결과 `AL = 4` (`00000100b`)이며, 1인 비트의 개수가 1개(홀수)이므로 패리티 플래그는 0이 됩니다.

6. **`mov eax, 5` / `sub eax, 6` 실행 후 EAX 및 Sign Flag(SF) 값**
   * **답:** **EAX = `FFFFFFFFh` (-1), SF = 1 (Set)**
   * **해설:** 결과가 음수이므로 최상위 비트(MSB)가 1이 되어 Sign Flag가 설정됩니다.

7. **`mov al, -1` / `add al, 130` 실행 시 Overflow Flag(OF) 역할 설명**
   * **답:** 8비트 부호 있는 정수 표현 범위는 **-128 ~ +127**입니다. `-1`(`FFh`)과 `130`(`82h` = -126)의 부호 연산 결과는 `-127`(`81h`)이며, 이는 부호 있는 8비트 범위 내에 존재하므로 **Overflow Flag는 0(Set 되지 않음)**이 됩니다. 따라서 OF는 연산 결과가 유효한 범위 내에 있음을 정확하게 나타냅니다.

8. **`mov rax, 44445555h` 실행 후 RAX 값**
   * **답:** **`0000000044445555h`**
   * **해설:** 64비트 모드에서 32비트 상수/피연산자를 64비트 레지스터로 이동하면 상위 32비트가 0으로 초기화(Zero-extension)됩니다.

9. **`dwordVal DWORD 84326732h` / `mov rax, 0FFFFFFFF00000000h` / `mov rax, dwordVal` 실행 후 RAX 값**
   * **답:** **`0000000084326732h`**
   * **해설:** 32비트 메모리 피연산자를 64비트 레지스터로 대입하면 상위 32비트 영역이 제로 확장되어 0으로 지워집니다.

10. **`dVal DWORD 12345678h` / `mov ax, 3` / `mov WORD PTR dVal+2, ax` / `mov eax, dVal` 실행 후 EAX 값**
    * **답:** **`00035678h`**
    * **해설:** x86 리틀 엔디안 저장 방식에 의해 `dVal+2` 위치는 상위 워드인 `1234h`를 가리킵니다. 이 값을 `0003h`로 변경하므로 전체 값은 `00035678h`가 됩니다.

11. **`mov dVal, 12345678h` / `mov ax, WORD PTR dVal+2` / `add ax, 3` / `mov WORD PTR dVal, ax` / `mov eax, dVal` 실행 후 EAX 값**
    * **답:** **`12341237h`**
    * **해설:** `ax = 1234h + 3 = 1237h`가 된 후, `dVal`의 하위 워드(`5678h`) 자리에 대입되므로 결과는 `12341237h`가 됩니다.

12. **양수와 음수를 더할 때 Overflow Flag가 설정될 수 있는가?**
    * **답:** **No (아니오)**
    * **해설:** 서로 다른 부호의 정수를 더할 때는 결과의 절대값이 감소하므로 표현 범위를 초과하는 오버플로가 절대로 발생하지 않습니다.

13. **음수와 음수를 더해 양수 결과가 나오면 Overflow Flag가 설정되는가?**
    * **답:** **Yes (예)**
    * **해설:** 음수끼리 더해서 표현 가능한 최소 범위를 밑돌면(Underflow) 부호 비트가 0(양수)으로 뒤집히며 OF가 1로 설정됩니다.

14. **`NEG` 명령어가 Overflow Flag를 설정할 수 있는가?**
    * **답:** **Yes (예)**
    * **해설:** 부호 있는 타입의 최소값(예: 8비트의 `-128`)에 `NEG`를 실행하면 `+128`이 되어 양수 표현 범위를 초과하므로 OF가 1이 됩니다.

15. **Sign Flag와 Zero Flag가 동시에 1로 설정될 수 있는가?**
    * **답:** **No (아니오)**
    * **해설:** 결과가 0이면 ZF=1이고 최상위 비트는 0(SF=0)입니다. 반대로 SF=1이면 결과가 음수(최상위 비트 1)이므로 0일 수 없습니다.

16. **다음 지시문들의 유효성(Valid / Invalid) 여부**
    * a. `mov ax, var1` \\(\rightarrow\\) **Invalid** (피연산자 크기 불일치: AX는 16비트, var1은 8비트).
    * b. `mov ax, var2` \\(\rightarrow\\) **Valid** (AX와 var2 모두 16비트).
    * c. `mov eax, var3` \\(\rightarrow\\) **Invalid** (크기 불일치: EAX는 32비트, var3은 16비트).
    * d. `mov var2, var3` \\(\rightarrow\\) **Invalid** (메모리 간 직접 이동 불가).
    * e. `movzx ax, var2` \\(\rightarrow\\) **Invalid** (`MOVZX` 소스 피연산자는 목적지보다 작아야 함).
    * f. `movzx var2, al` \\(\rightarrow\\) **Invalid** (`MOVZX` 목적지는 레지스터여야 함).
    * g. `mov ds, ax` \\(\rightarrow\\) **Valid** (16비트 레지스터에서 세그먼트 레지스터로 이동 가능).
    * h. `mov ds, 1000h` \\(\rightarrow\\) **Invalid** (세그먼트 레지스터에 즉시값 직접 이동 불가).

17. **순차 실행 후 목적지 피연산자의 16진수 값**
    * a. `mov al, var1` \\(\rightarrow\\) **`FCh`** (`-4`를 8비트 2진수로 표현).
    * b. `mov ah, [var1+3]` \\(\rightarrow\\) **`01h`** (`var1` 배열의 4번째 요소인 `1`).

18. **순차 실행 후 목적지 피연산자의 값**
    * a. `mov ax, var2` \\(\rightarrow\\) **`1000h`**
    * b. `mov ax, [var2+4]` \\(\rightarrow\\) **`3000h`** (WORD 타입이므로 4바이트 이동 후 3번째 요소).
    * c. `mov ax, var3` \\(\rightarrow\\) **`FFF0h`** (`-16`을 16비트 16진수로 표현).
    * d. `mov ax, [var3-2]` \\(\rightarrow\\) **`4000h`** (메모리상 바로 앞인 `var2` 배열의 마지막 요소).

19. **순차 실행 후 목적지 피연산자의 값**
    * a. `mov edx, var4` \\(\rightarrow\\) **`00000001h`**
    * b. `movzx edx, var2` \\(\rightarrow\\) **`00001000h`** (`var2` 첫 값인 `1000h`를 제로 확장).
    * c. `mov edx, [var4+4]` \\(\rightarrow\\) **`00000002h`** (DWORD 4바이트 뒤인 2번째 요소).
    * d. `movsx edx, var1` \\(\rightarrow\\) **`FFFFFFFCh`** (`var1` 첫 값인 `-4`를 부호 확장).

#### **4.9.2 Algorithm Workbench**

1. **더블워드 변수 `three` 상위 워드와 하위 워드 교환**
```assembly
mov ax, WORD PTR [three]       ; 하위 워드
mov dx, WORD PTR [three + 2]   ; 상위 워드
mov WORD PTR [three], dx       ; 하위 위치에 상위 워드 저장
mov WORD PTR [three + 2], ax   ; 상위 위치에 하위 워드 저장
```

2. **`XCHG` 명령어를 3회 이하 사용하여 (A,B,C,D) 순서를 (B,C,D,A)로 변경**
```assembly
xchg al, bl    ; AL=B, BL=A (현재: B, A, C, D)
xchg bl, cl    ; BL=C, CL=A (현재: B, C, A, D)
xchg cl, dl    ; CL=D, DL=A (현재: B, C, D, A)
```

3. **`AL` 레지스터의 패리티(짝수/홀수) 검사**
```assembly
add al, 0      ; 값 변경 없이 상태 플래그만 업데이트
jp EvenParity  ; Parity Flag = 1 (짝수 패리티)이면 이동
```

4. **두 음수를 더해 Overflow Flag를 설정시키는 예제**
```assembly
mov al, -100   ; 8비트 부호 범위: -128 ~ +127
add al, -50    ; -100 + (-50) = -150 (범위 초과로 OF = 1 설정)
```

5. **덧셈 연산으로 Zero Flag와 Carry Flag를 동시에 설정**
```assembly
mov al, 0FFh
add al, 1      ; AL = 00h (ZF = 1), 캐리 발생 (CF = 1)
```

6. **뺄셈 연산으로 Carry Flag 설정**
```assembly
mov al, 1
sub al, 2      ; 작은 수에서 큰 수를 빼므로 CF = 1 설정
```

7. **`EAX = –val2 + 7 – val3 + val1` 구현**
```assembly
mov eax, val2
neg eax        ; -val2
add eax, 7     ; -val2 + 7
sub eax, val3  ; -val2 + 7 - val3
add eax, val1  ; -val2 + 7 - val3 + val1
```

8. **인덱스 주소 지정과 스케일 팩터로 더블워드 배열 합계 계산**
```assembly
.data
arrayD DWORD 10h, 20h, 30h, 40h
.code
mov esi, 0
mov ecx, LENGTHOF arrayD
mov eax, 0
L1:
    add eax, arrayD[esi * TYPE arrayD]
    inc esi
    loop L1
```

9. **`AX = (val2 + BX) – val4` 구현**
```assembly
mov ax, val2
add ax, bx     ; val2 + BX
sub ax, val4   ; (val2 + BX) - val4
```

10. **Carry Flag와 Overflow Flag를 동시에 설정**
```assembly
mov al, 80h    ; -128
add al, 80h    ; -128 + (-128) = -256 (OF=1, CF=1)
```

11. **`INC`/`DEC` 후 ZF로 부호 없는 오버플로 감지**
```assembly
inc al         ; AL이 0FFh였으면 00h가 되면서 ZF = 1 설정
jz Overflow    ; ZF = 1 이면 부호 없는 오버플로 발생을 의미
```

12. **`myBytes`를 짝수 주소에 정렬하는 지시어 삽입**
```assembly
ALIGN 2
myBytes BYTE 10h, 20h, 30h, 40h
```

13. **연산자 실행 후 EAX 값**
    * a. `mov eax, TYPE myBytes` \\(\rightarrow\\) **`1`**
    * b. `mov eax, LENGTHOF myBytes` \\(\rightarrow\\) **`4`**
    * c. `mov eax, SIZEOF myBytes` \\(\rightarrow\\) **`4`**
    * d. `mov eax, TYPE myWords` \\(\rightarrow\\) **`2`**
    * e. `mov eax, LENGTHOF myWords` \\(\rightarrow\\) **`4`** (`3 + 1`)
    * f. `mov eax, SIZEOF myWords` \\(\rightarrow\\) **`8`** (`4 * 2`)
    * g. `mov eax, SIZEOF myString` \\(\rightarrow\\) **`5`** (`"ABCDE"` 5바이트)

14. **`myBytes` 처음 두 바이트를 DX로 이동 (`DX = 2010h`)**
```assembly
mov dx, WORD PTR myBytes   ; 리틀 엔디안으로 DX에 2010h 저장
```

15. **`myWords` 두 번째 바이트를 AL로 이동**
```assembly
mov al, BYTE PTR [myWords + 1]
```

16. **`myBytes` 4바이트를 EAX로 이동**
```assembly
mov eax, DWORD PTR myBytes
```

17. **`myWords`를 32비트 레지스터로 직접 이동 가능하게 하는 `LABEL` 지시어**
```assembly

```

18. **`myBytes`를 16비트 레지스터로 직접 이동 가능하게 하는 `LABEL` 지시어**

### **4.10 Programming Exercises (프로그래밍 실습)**

1. **Big Endian을 Little Endian으로 변환**
```assembly
.386
.model flat, stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.data
bigEndian    BYTE 12h, 34h, 56h, 78h
littleEndian DWORD ?

.code
main PROC
    mov al, [bigEndian]      ; 12h
    mov ah, [bigEndian + 1]  ; 34h
    mov WORD PTR [littleEndian + 2], ax ; 상위 워드에 3412h 저장

    mov al, [bigEndian + 2]  ; 56h
    mov ah, [bigEndian + 3]  ; 78h
    mov WORD PTR [littleEndian], ax     ; 하위 워드에 7856h 저장

    INVOKE ExitProcess, 0
main ENDP
END main
```

2. **배열 요소 쌍(Pair) 교환하기**
```assembly
.386
.model flat, stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.data
array DWORD 1, 2, 3, 4, 5, 6, 7, 8

.code
main PROC
    mov esi, 0
    mov ecx, LENGTHOF array / 2   ; 4개 쌍 반복

L1:
    mov eax, array[esi]
    xchg eax, array[esi + 4]
    mov array[esi], eax
    add esi, 8                   ; 다음 쌍으로 이동
    loop L1

    INVOKE ExitProcess, 0
main ENDP
END main
```

3. **배열 요소 간 차이(Gap)의 합계 계산**
```assembly
.386
.model flat, stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.data
array DWORD 0, 2, 5, 9, 10
sum   DWORD 0

.code
main PROC
    mov esi, 0
    mov ecx, LENGTHOF array - 1   ; 4개의 gap 계산
    mov eax, 0                   ; 누적 합계

L1:
    mov ebx, array[esi + 4]
    sub ebx, array[esi]          ; gap = array[i+1] - array[i]
    add eax, ebx
    add esi, 4
    loop L1

    mov sum, eax
    INVOKE ExitProcess, 0
main ENDP
END main
```

4. **WORD 배열을 DWORD 배열로 복사**
```assembly

    mov edi, 0

L1:

```

5. **피보나치 수열 7개 계산**

6. **배열 제자리(In-place) 뒤집기**
```assembly
.386
.model flat, stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.data
array DWORD 1, 2, 3, 4, 5, 6, 7, 8

.code
main PROC
    mov esi, 0
    mov edi, SIZEOF array - TYPE array  ; 마지막 요소의 오프셋
    mov ecx, LENGTHOF array / 2

L1:
    mov eax, array[esi]
    xchg eax, array[edi]
    mov array[esi], eax
    add esi, TYPE array
    sub edi, TYPE array
    loop L1

    INVOKE ExitProcess, 0
main ENDP
END main
```

7. **문자열 역순 복사**
```assembly
.386
.model flat, stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.data
source BYTE "This is the source string", 0
target BYTE SIZEOF source DUP('#')

.code
main PROC
    mov esi, OFFSET source + SIZEOF source - 2 ; null 문자를 제외한 마지막 글자
    mov edi, OFFSET target
    mov ecx, SIZEOF source - 1

L1:
    mov al, [esi]
    mov [edi], al
    dec esi
    inc edi
    loop L1

    mov BYTE PTR [edi], 0                      ; null 종문자 추가

    INVOKE ExitProcess, 0
main ENDP
END main
```

8. **배열 요소 회전(Shift / Rotate) 시키기**
```assembly
.386
.model flat, stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.data
array DWORD 10, 20, 30, 40

.code
main PROC
    mov ecx, LENGTHOF array - 1
    mov esi, SIZEOF array - TYPE array   ; 마지막 오프셋에서 시작
    mov eax, array[esi]                  ; 마지막 요소(40) 백업

L1:
    mov ebx, array[esi - TYPE array]
    mov array[esi], ebx
    sub esi, TYPE array
    loop L1

    mov array, eax                    ; 마지막 요소를 첫 번째 위치로 복사

    INVOKE ExitProcess, 0
main ENDP
END main
```
