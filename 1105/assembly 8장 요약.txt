

1. 스택 프레임 및 매개변수 전달 (Stack Frames & Parameter Passing)
-------------------------------------------------------------------
- 스택 프레임(Stack Frame / Activation Record): 프로시저 호출 시 스택에 생성되는 영역으로 복귀 주소, 이전 EBP(Base Pointer), 매개변수, 지역 변수가 위치함.
- 프롤로그(Prologue) & 에필로그(Epilogue):
  * 프롤로그: push ebp / mov ebp, esp / sub esp, N (스택 프레임 생성 및 지역변수 공간 확보)
  * 에필로그: mov esp, ebp / pop ebp / ret N (스택 프레임 해제 및 스택 정리)
- 매개변수 전달 방식:
  * 값 전달(Pass by Value): 값 자체를 PUSH하여 전달 ([ebp+8], [ebp+12] 등 오프셋 접근)
  * 참조 전달(Pass by Reference): 변수의 메모리 주소(OFFSET)를 PUSH하여 전달
- 호출 규약(Calling Conventions):
  * STDCALL: 피호출자(Callee)가 스택 정리 (ret N 명령어 사용)
  * CDECL: 호출자(Caller)가 스택 정리 (call 후 add esp, N 수행)

/* 예제 코드: 스택 프레임 및 매개변수 전달 수동 구현 (STDCALL 방식) */
.code
;-------------------------------------------------------------------
; AddTwo: 스택으로 전달받은 두 정수의 합을 구함 (STDCALL)
; [ebp+12] = 두 번째 매개변수, [ebp+8] = 첫 번째 매개변수
;-------------------------------------------------------------------
AddTwo PROC
    push ebp
    mov  ebp, esp        ; 스택 프레임 생성
    mov  eax, [ebp+8]    ; 첫 번째 매개변수 로드
    add  eax, [ebp+12]   ; 두 번째 매개변수 가산
    pop  ebp             ; 이전 EBP 복원
    ret  8               ; 스택 정리 (매개변수 8바이트 제거)
AddTwo ENDP

; 프로시저 호출부
push 20
push 10
call AddTwo              ; EAX = 30 반환

2. 지역 변수 및 LEA / ENTER / LEAVE 명령어
-------------------------------------------------------------------
- LOCAL 지시어: MASM에서 스택 상의 지역 변수를 자동 할당 (예: LOCAL temp:DWORD, ptrArray:DWORD)
- LEA (Load Effective Address): 주소 계산 연산자로, 스택 상 지역 변수나 간접 메모리의 오프셋 주소를 EAX에 로드할 때 사용 (mov eax, OFFSET [ebp-4]는 불가능하므로 lea 사용)
- ENTER bytes, level: 프롤로그 연산(push ebp / mov ebp, esp / sub esp, bytes)을 한 번에 실행
- LEAVE: 에필로그 연산(mov esp, ebp / pop ebp)을 한 번에 실행

/* 예제 코드: LOCAL 지시어 및 LEA 명령어 활용 */
.code
MySub PROC
    LOCAL temp:DWORD, ptrArray:DWORD  ; EBP-4, EBP-8에 지역변수 자동 할당
    
    mov temp, 100        ; [ebp-4] = 100
    lea eax, temp        ; temp의 스택 오프셋 주소를 EAX에 로드
    mov ptrArray, eax    ; [ebp-8] = EAX
    
    ret                  ; 어셈블러가 leave(esp, ebp 복원) 자동 삽입
MySub ENDP

3. 고급 지시어: PROTO, PROC, INVOKE (MASM Directives)
-------------------------------------------------------------------
- PROTO: 프로시저 프로토타입 선언 지시어로 파라미터 타입과 개수를 미리 명시
- PROC: 파라미터 리스트를 포함하여 프로시저를 선언하며, 매개변수명으로 직접 참조 가능
- INVOKE: 타입 검사와 함께 매개변수 PUSH 및 CALL 명령어를 자동으로 생성해 주는 고급 함수 호출 지시어 (ADDR 연산자로 오프셋 전달 가능)

/* 예제 코드: PROTO, PROC, INVOKE 활용 */
; 1) 프로토타입 선언
ArraySum PROTO,
    ptrArray:PTR DWORD,
    szArray:DWORD

.code
main PROC
    ; 2) INVOKE를 이용한 간편한 프로시저 호출
    INVOKE ArraySum, ADDR myArray, LENGTHOF myArray
    exit
main ENDP

; 3) 파라미터가 명시된 PROC 정의
ArraySum PROC,
    ptrArray:PTR DWORD,
    szArray:DWORD
    
    mov esi, ptrArray
    mov ecx, szArray
    mov eax, 0
L1:
    add eax, [esi]
    add esi, TYPE DWORD
    loop L1
    ret
ArraySum ENDP

4. 재귀 프로시저 (Recursion)
-------------------------------------------------------------------
- 자기 자신을 호출하는 프로시저로 기저 조건(Base Case)과 재귀 단계(Recursive Step)로 구성
- 호출이 일어날 때마다 새로운 스택 프레임이 계속 쌓이며, 기저 조건에 도달하면 역순으로 스택 프레임이 해제됨

/* 예제 코드: N! (팩토리얼) 계산 재귀 프로시저 */
.code
Factorial PROC
    cmp eax, 0          ; Base Case: 0! = 1
    ja  L1
    mov eax, 1
    ret

L1:
    push eax            ; n 보존
    dec  eax            ; n - 1
    call Factorial      ; Factorial(n - 1) 호출
    pop  ebx            ; 원래 n 복원
    mul  ebx            ; EAX = Factorial(n - 1) * n
    ret
Factorial ENDP

5. 다중 모듈 프로그램 작성 (Multimodule Programs)
-------------------------------------------------------------------
- 프로그램을 여러 개의 `.asm` 독립 소스 파일로 분할하여 작성 및 빌드
- PUBLIC 지시어: 현재 모듈에 정의된 프로시저/변수를 다른 모듈에서 접근할 수 있도록 공개
- EXTERN 지시어: 다른 외부 모듈에 정의된 프로시저/변수를 참조할 때 사용

/* 예제 코드: PUBLIC과 EXTERN을 활용한 다중 모듈 구성 */
; --- sub1.asm (서브 모듈) ---
.code
PUBLIC SubRoutine
SubRoutine PROC
    mov eax, 100
    ret
SubRoutine ENDP
END

; --- main.asm (메인 모듈) ---
EXTERN SubRoutine@0:PROC  ; 외부 모듈의 서브루틴 참조 선언

.code
main PROC
    call SubRoutine
    exit
main ENDP
END main
